#  In-Memory Account Ledger
This application runs on java 27


---

## How to Run

1. Make the run script executable:
   ```bash
   chmod +x run.sh
   ```
2. Execute the build and run script:
   ```bash
   ./run.sh
   ```
3. At startup, choose your execution mode:
    *  Runs the automated 6-day simulation testcase with failed events.
